# 素材与书目来源

- 个人照片：用户指定的 JPEG，见 [xiangshang.jpeg](../assets/photos/xiangshang.jpeg)。
- 国科大标识：[官方标识系统](https://onestop.ucas.edu.cn/home/info/6b9e95dc-5785-4eee-b25f-1f884698cfc3) 的[标准包](https://onestop.ucas.edu.cn/Content/Upload/2020/9/1.zip)，使用圆形中国科学院院徽图形。
- 湖北大学校徽：[视觉形象识别系统](https://news.hubu.edu.cn/info/1052/34040.htm) 中的[标准色校标原图](https://news.hubu.edu.cn/__local/8/2D/42/7344792910E02EA9380E0F2324C_2410A704_F515.png)。
- 西安交通大学校徽：[校标组合规范](https://vi.xjtu.edu.cn/jcbf/xbzhgf.htm) 的[蓝色校徽原图](https://vi.xjtu.edu.cn/images/a3-2jdxhblue.png)。
- 论文框架图：本人论文的 Fig. 2，使用出版商提供的[高清原图](https://ars.els-cdn.com/content/image/1-s2.0-S0925231225019800-gr2_lrg.jpg)和缩略图，未重绘。论文：[Neurocomputing 654 (2025), 131308](https://doi.org/10.1016/j.neucom.2025.131308)。
- 学术链接图标：Font Awesome Free 6.4.2 的毕业帽、ORCID、GitHub、信封 SVG，原始许可见 [fontawesome-license.txt](../assets/fontawesome-license.txt)。
- 研究标签、论文入口与资源入口：本项目内联线条 SVG；网站图标使用内置 imagegen 生成的 S 形上升箭头，见 [site-mark.png](../assets/icons/site-mark.png)。
- 字体：Google Fonts 的 Crimson Pro 与 Ubuntu Mono，无法加载时回退为系统字体。

校徽、字体与出版商图件的权利归各自权利人。第三方学习资源的链接及简介在 [resources.yml](../_data/resources.yml) 维护。
